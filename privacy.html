Privacy Policy: Actually True Uploader

Last updated: 23 November 2026

Actually True Uploader is a private tool used only by the owner of the YouTube channels "Actually True" and "Actually Not True".

What it accesses

  • With the owner's consent through Google sign-in, it uses the YouTube Data API to upload, schedule and set thumbnails for videos on the owner's own channels.
  • It uses the YouTube Analytics API (read-only) to read performance reports for the owner's own channels.

What it stores

Google sign-in tokens are stored only on the owner's own computer. Channel data is used only by the owner to improve their videos. Nothing is sold, shared with third parties or used for advertising.

Other users

The tool is not offered to the public and does not collect data about any other person.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.
